# Porting to the Rise app (for Claude Code)

Target: React 19 + Vite, plain CSS, no Tailwind/component library. Web UI shared by PWA, Android shell and Tauri desktop.

1. **Tokens.** Copy `tokens/*.css` into `src/css/` (or concatenate into `tokens.css`) and import once. Replace old `--surface-*`/`--text-*` aliases with the semantic names here. Old→new: canvas `--surface-canvas`→`--bg-canvas`; card→`--bg-raised`; sunken→`--bg-sunken`; `--text-*`→`--ink`, `--ink-muted`, `--ink-soft`; coral text `--text-link`→`--accent-text`; `--intake-*` names are unchanged. The old accent `#CC785C` becomes `#E0673F`.
2. **Look + theme.** `<html data-look data-theme>`. Persist `lookPref` next to `themePref`; resolve "System" in JS from `prefers-color-scheme` and write `data-theme` (no duplicated dark block in a media query).
3. **Fonts.** Vendor woff2 into `public/assets/fonts/`: Fraunces, Atkinson Hyperlegible Next (already in `assets/fonts`), plus **download** Newsreader (400/500/400i) and Barlow Semi Condensed (500/600/700). Replace the Google `@import` in `tokens/fonts.css`; add them to the service-worker precache.
4. **Components.** Port `components/**/*.jsx` into `src/components/`. They use inline style objects over CSS variables so they are trivially convertible to class-based CSS in `app.css` if preferred; keep the variable names. Hover/press/focus-visible are best expressed in CSS (`:hover` inside `@media (hover:hover) and (pointer:fine)`, `:active`, `:focus-visible { box-shadow: var(--focus-ring) }`) — the JSX only implements press scale on Button.
5. **Screens.** Map to existing files: `Today.jsx` ← DotStrip, DayTotal, BlockList/BlockRow/NowMarker/DueCard, Sheet (Log food, Swap, Add a block, Calendar), Banner, Chip; `Weight.jsx` ← WeightChart, SuggestionCard, StatRow, Sheet/dialog; `Plan.jsx` ← GroceryList, PhaseLadder; `Settings.jsx` ← ListGroup/ListRow, Toggle, Segmented, Look tiles, ConfirmPanel; `Recipes.jsx` ← EmptyState, TextField, Sheet. Reference layouts: `ui_kits/rise/` and the original `Rise *.dc.html` files (open `Rise Screens.dc.html`).
6. **Desktop.** 256px `SideNav` (Recipes is the fifth item), 1080px content column, 340px support column, dialogs 520px centred on the main pane, toasts at the foot of the main pane. The desktop row/due-card variants are in `ui_kits/rise/DesktopApp.jsx`.
7. **Business rules that shape UI:** `scaleGroceryQty` scales quantities from the Phase 2 baseline; changed quantities show in `--accent-text` until the Monday reset; ticks carry over. Recipes is reached from the foot of Plan on phone (Plan tab stays lit).
8. **Verify:** 390×844, 320 stress (nothing clips), 1440×900, Paper/Reel × light/dark, reduced motion, contrast ≥4.5:1 for body text.
